# Pintarika Perkalian - versi Vercel (untuk tugas/demo)
PERHATIAN: database ada di /tmp Vercel, jadi data bisa hilang kapan saja (cold start/redeploy).
Cocok untuk demo, bukan data sungguhan.

Environment Variables di Vercel:
  GURU_PASS = sandi guru (wajib)
  DEMO      = 1  (membuat siswa contoh 01458291 / siswa123)
Login guru: pengguna "guru" + sandi GURU_PASS.

Deploy: lihat langkah di chat (Vercel CLI atau GitHub).
Jalankan lokal: node server.js (Node 22.13+)
